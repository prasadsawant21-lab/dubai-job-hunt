# Dubai Job Hunt Command Center

Personalized job search dashboard for **Prasad V. Sawant** — targeting Performance Director and Head of Growth roles at Tier 1 tech platforms and Tier 2 media agencies in Dubai.

## Features

- **🔄 Refresh button** — Opens live searches on LinkedIn, Indeed, Bayt, and GulfTalent with fresh date filters
- **Live jobs feed** — Curated openings ranked by fit-score against your resume
- **36 target companies** — Tier 1 (Google, Meta, TikTok, Snap, etc.) + Tier 2 agencies (IPG, WPP, Publicis, etc.) + Tier 3 in-house
- **Outreach templates** — 6 pre-written messages for cold outreach, warm reconnects, recruiter contact
- **Application tracker** — Saves locally in browser via localStorage
